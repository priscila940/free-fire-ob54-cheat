# Free Fire OB54 Cheat

A lightweight external cheat for Free Fire OB54 with ESP, Aimbot, and FOV controls.

## Features
- ESP (Enemy Sightseeing Program)
  - Box ESP
  - Line ESP
  - Name ESP
  - Distance ESP
  - Life ESP
- Combat Features
  - Adjustable FOV (0-500)
  - Aimbot
  - Smoothness control (0-100)

## Installation
1. Download the latest release from the releases page
2. Run as Administrator

## Building from Source
```bash
pip install pyinstaller
pyinstaller --onefile --noconsole src/free_fire_ob54_cheat.py
